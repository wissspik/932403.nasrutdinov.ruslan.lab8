## Возможности

- Полный CRUD объявлений: создание, просмотр, редактирование и удаление.
- Поиск по заголовку.
- Фильтрация по категории, статусу и диапазону цен.
- Карточки объявлений и заметный индикатор «Продано».
- Модальное окно добавления/редактирования.
- Клиентская и серверная валидация, включая запрет отрицательной цены.
- Адаптивная вёрстка, семантические элементы, labels и ARIA-атрибуты.
- Безопасный вывод пользовательского контента через `textContent`.
- API-тесты на CRUD, фильтры и граничные значения.

## Схема БД

```text
ads
├── id INTEGER PRIMARY KEY AUTOINCREMENT
├── title TEXT NOT NULL
├── description TEXT NOT NULL
├── price REAL NOT NULL CHECK(price >= 0)
├── category TEXT NOT NULL
└── status TEXT CHECK(status IN ('active', 'sold', 'archived'))
```

SQL-скрипт создания таблицы находится в `schema.sql`.

## API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/api/ads` | Получить объявления |
| `GET` | `/api/ads/:id` | Получить одно объявление |
| `POST` | `/api/ads` | Создать объявление |
| `PUT` | `/api/ads/:id` | Обновить объявление |
| `DELETE` | `/api/ads/:id` | Удалить объявление |
| `GET` | `/api/categories` | Список категорий |

Параметры фильтрации `GET /api/ads`:

- `category` — категория;
- `status` — `active`, `sold` или `archived`;
- `minPrice`, `maxPrice` — диапазон цены;
- `q` — поиск по заголовку.

Пример тела `POST`/`PUT`:

```json
{
  "title": "Настольная лампа",
  "description": "Три режима яркости, отличное состояние.",
  "price": 1800,
  "category": "Дом",
  "status": "active"
}
```

## Запуск

Требуется Node.js 22.5 или новее (используется встроенный `node:sqlite`).

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. База создаётся автоматически в `data/ads.db`.
